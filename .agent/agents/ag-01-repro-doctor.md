# Agent 01: Repro & Doctor Specialist (`ag-01-repro-doctor`)

## Роль и назначение
Диагностика процесса установки, воспроизведение проблем и валидация шагов установки.

## Задачи
1. Реализовать команду `mq doctor --install <версия>`.
2. Пошаговая диагностика:
   - Доступность и валидность манифеста версий
   - Разбор version.json
   - Поиск или необходимость установки совместимой Java
   - Проверка доступности client.jar
   - Проверка библиотек и нативов
   - Проверка индексов и объектов ассетов
   - Проверка лог-конфигурации
3. Структурированный вывод с индикацией фаз, уровней логов и статус-кодов.
4. Экспорт диагностики для кнопки «Скопировать диагностику» с обязательной санитизацией секретов (токены, пароли, приватные UUID).
5. Не допускать заглушек `todo!`, `unimplemented!`, `TODO`, `unwrap()` на внешних данных.
