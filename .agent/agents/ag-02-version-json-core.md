# Agent 02: Version JSON Core Specialist (`ag-02-version-json-core`)

## Роль и назначение
Ядро метаданных версий, разбор `version.json` всех эпох, поддержка схемы 26.x, правила `rules` и безопасное раскрытие аргументов.

## Задачи
1. Поддержка схемы версий Mojang `26.x`, `26.1-snapshot-1`, `-pre-`, `-rc-`: запрет на разбор идентификаторов как semver `1.x.y`, сортировка и тип только из манифеста.
2. Безопасный парсинг `version.json`: `#[serde(default)]`, игнорирование неизвестных полей (отсутствие `deny_unknown_fields`).
3. Корректная оценка правил `rules`: ОС (`linux`, `osx`, `windows`), архитектура (`x86_64`, `arm64`), фичи (`features`).
4. Раскрытие всех `${...}` плейсхолдеров в `arguments.game` и `arguments.jvm`:
   - Ни один неподставленный `${...}` не должен попадать в итоговую строку запуска JVM/игры.
   - Тесты на отсутствие неподставленных `${...}`.
5. Поддержка наследования `inheritsFrom` для модлоадеров и кастомных профилей.
6. Сохранение `logging.client.file` и формирование `-Dlog4j.configurationFile=...`.
