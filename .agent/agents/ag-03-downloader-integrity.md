# Agent 03: Downloader & Integrity Specialist (`ag-03-downloader-integrity`)

## Роль и назначение
Сетевой движок, целостность данных, атомарная файловая система, транзакционность и состояние установки.

## Задачи
1. Транзакционность установки:
   - Установка во временный каталог `<instance>/.installing/`.
   - Запись и поддержание `<instance>/install_state.json` (схема из `docs/CONTRACTS.md`).
   - Фиксация состояния «Готов к запуску» только при валидности всех файлов.
2. Сетевая надежность:
   - Запись в `.part` и атомарное переименование после сверки SHA-1 и размера.
   - Повторы с экспоненциальной задержкой и джиттером для 429/5xx и обрывов соединения, обработка `Retry-After`.
   - Возобновление прерванных загрузок (докачка только недостающего).
3. Проверка свободного места на диске перед началом загрузки.
4. Безопасность блокировок параллельных установок одной версии/инстанса.
5. Использование официальных хэшей Mojang для проверки целостности.
