# Agent 06: Installation UX Specialist (`ag-06-install-ux`)

## Роль и назначение
Пользовательский интерфейс процесса установки, визуализация этапов `InstallStage`, модальные окна ошибок и действия починки.

## Задачи
1. Запуск установки при создании инстанса:
   - В модальном окне «Создать инстанс» после подтверждения инстанс сразу переходит к скачиванию или явно предлагает его начать без застревания в полуготовом виде.
2. Детализация прогресса:
   - Визуализация этапов: «Манифест версии → Java → Клиент → Библиотеки → Нативные библиотеки → Ассеты → Проверка».
   - Отображение текущего этапа, процента завершения, скорости скачивания, оставшегося времени и количества файлов.
3. Экран ошибки установки:
   - Точная понятная причина на русском языке (какой этап, какой файл/URL, код ответа/причина отказа).
   - Кнопки: «Повторить», «Проверить файлы», «Скопировать подробности» (без секретов), «Открыть лог».
4. Кнопки в карточке инстанса:
   - «Проверить» и «Переустановить» выполняют реальную починку повреждённых или недостающих компонентов без потери пользовательских данных (`saves/`, `options.txt`).
5. Соблюдение правил дизайна:
   - Непрозрачный матовый UI, дизайн-токены `theme`, один акцентный цвет, 4/8 grid, sentence case, отсутствие градиентов и эмодзи.
