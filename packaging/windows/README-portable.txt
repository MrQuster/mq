[ENGLISH]
Thank you for downloading the portable edition of MQ Launcher!

This package is completely self-contained and leaves no traces in your Windows
system registry or AppData directories.

Contents:
  - mq.exe            : Main MQ Launcher executable (compiled with Rust)
  - portable.flag     : Tells MQ to store instances, mods, and settings locally
  - mq.ico            : High-resolution application icon
  - run.bat           : Helper launcher script
  - README.txt        : This quick start guide

How to run:
  - Simply double-click `mq.exe` or `run.bat`.
  - All game instances, downloaded mods, and configurations will be stored
    inside the `./data` directory next to `mq.exe`.
  - You can copy this folder to a USB flash drive or another PC.

System Requirements:
  - Windows 10 (version 1809+) or Windows 11 (x86_64)
  - Java 17 or 21 (MQ will detect system Java or prompt to download Adoptium Temurin)

[РУССКИЙ]
Спасибо за выбор портативной версии MQ Launcher!

Этот архив полностью автономен и не требует установки с правами администратора,
а также не засоряет системный реестр и папки пользователя.

Содержимое:
  - mq.exe            : Главный исполняемый файл лаунчера MQ (написан на Rust)
  - portable.flag     : Флаг портативного режима (данные сохраняются локально)
  - mq.ico            : Иконка лаунчера в высоком разрешении
  - run.bat           : Вспомогательный батник для быстрого запуска
  - README.txt        : Данная инструкция

Как запустить:
  - Дважды щелкните по `mq.exe` или запустите `run.bat`.
  - Все сборки Minecraft, моды, конфиги и аккаунты будут храниться
    в папке `./data` прямо рядом с `mq.exe`.
  - Папку с лаунчером можно переносить на флешке или перемещать в любое место.

Требования:
  - Windows 10 (1809+) или Windows 11 (x86_64)
  - Java 17 или 21 (рекомендуется Adoptium Temurin OpenJDK)
