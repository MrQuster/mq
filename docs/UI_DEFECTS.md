# Реестр дефектов интерфейса и решений (MQ v2.1.0 Solid Edition)

В рамках релиза **MQ v2.1.0 "Solid Edition"** проведён комплексный аудит интерфейса лаунчера. Устранены визуальные дефекты, нестабильности рендеринга на графических стеках Linux (Wayland/X11), переработана компоновка экранов по принципам лучших десктопных приложений (Modrinth App, Prism Launcher, Linear).

---

## Таблица дефектов и исправлений (B1 — B20)

| ID | Область / Экран | Исходный дефект (Finding) | Реализованное исправление (Fix) | Статус |
|:---|:---|:---|:---|:---:|
| **B1** | Окно приложения | Артефакты полупрозрачности окна (`with_transparent(true)`) на композиторах Linux (KDE KWin, Hyprland, Sway), дрожание фонового буфера. | Окно сделано строго непрозрачным (`with_transparent(false)`), применён глубокий монолитный фон `#0F1115`. | **Исправлено** |
| **B2** | Стилизация | Чрезмерное использование размытых градиентов и кислотных неоновых свечений ("AI-slop"), визуальный шум. | Переход на строгий Solid Dark дизайн: единый матовый акцент `#10B981` / `#3B82F6`, контрастные границы `#23272F`, выверенные радиусы 6px/8px. | **Исправлено** |
| **B3** | Консоль инстанса | Фиксированная высота окна консоли логов, обрезание последних строк при изменении размера окна. | Динамический расчет высоты через `available_height()` (минимум 240px), моноширинный шрифт 12pt, автоматическая прокрутка к последней записи. | **Исправлено** |
| **B4** | Элементы управления | Разнобой высот кнопок и полей ввода (24px, 28px, 36px), нарушение вертикального ритма. | Унификация всех интерактивных элементов (кнопки, селекторы, переключатели, поля ввода) к единому стандарту высоты 32px. | **Исправлено** |
| **B5** | Вкладки инстанса | Кнопки-таблетки в детальном виде инстанса визуально конфликтовали с кнопками действий. | Реализованы элегантные `render_underline_tabs` с тонкой 2px акцентной полосой активной вкладки и плавной подсветкой при наведении. | **Исправлено** |
| **B6** | Поля поиска | Текстовые поля поиска без кнопки быстрой очистки, иконки лупы и кольца фокуса. | Создан компонент `SearchField`: встроенная иконка лупы, кнопка крестика для очистки, горячая клавиша `Ctrl+F`, четкий фокус-ринг. | **Исправлено** |
| **B7** | Фильтры логов | Текстовые чекбоксы уровней логов без индикации количества сообщений. | Разработан компонент `FilterChip`: цветная индикация уровня (`INFO`, `WARN`, `ERROR`), бейдж с числом строк каждого типа. | **Исправлено** |
| **B8** | Карточки инстансов | Загромождение карточки яркими пестрыми плашками, сливающимися в сплошное пятно. | Пропорциональные плашки версий ("Vanilla · 26.3"), нейтральный серый бейдж оперативной памяти ("6 ГБ ОЗУ"), одиночный индикатор статуса. | **Исправлено** |
| **B9** | Текстовые метки | Непоследовательный регистр заголовков и кнопок (смесь Title Case и CAPS). | Строгий русский Sentence case во всех экранах ("Инстансы и сборки", "Папка модов", "Экспорт", "Настройки"). | **Исправлено** |
| **B10** | Тулбар инстанса | Нагромождение второстепенных кнопок ("Переустановить", "Дублировать") рядом с "Играть". | Четкая визуальная иерархия: доминирующая кнопка "Играть", быстрые иконки ("Папка игры", "Проверить") и выпадающее меню действий `...`. | **Исправлено** |
| **B11** | HiDPI рендеринг | Размытие тонких 1.5px векторных линий иконок на дробных масштабах (125%, 150%). | Принудительное округление координат до целых пикселей (`.round()`) в базовых функциях отрисовки векторных примитивов. | **Исправлено** |
| **B12** | Строка состояния | Непонятный технический жаргон в нижнем HUD ("DAG", "RSS", "ЦП"). | Понятные человеку формулировки: "Загрузки: нет активных", "Процессор", "Память", "Сторожевой таймер: 0". | **Исправлено** |
| **B13** | Левая колонка | Пустой экран инстансов не предлагал понятного действия по созданию первого инстанса. | Лаконичный заголовок "Инстансы", явное состояние пустого списка с заметной кнопкой создания нового инстанса. | **Исправлено** |
| **B14** | Режим отображения | Переключатель Сетка/Список не имел явной индикации выбранного режима и подсказок. | Векторный компонент `segmented_switch` со сменой состояний, микроанимацией и информативными подсказками. | **Исправлено** |
| **B15** | Авторизация Ely.by | Форма ввода логина/пароля в лаунчере, приводящая к ошибкам двухфакторной аутентификации. | Безопасный OAuth2 вход исключительно через браузер с локальным loopback-сервером (`127.0.0.1:25585/callback`). | **Исправлено** |
| **B16** | Выбор локали MC | Отсутствие быстрого поиска по более чем 80 встроенным игровым локалям Minecraft. | Поле мгновенного поиска локали по русскому и оригинальному названию с автосинхронизацией в `options.txt`. | **Исправлено** |
| **B17** | Самообновление | Отсутствие индикатора доступности новой версии лаунчера в основном меню. | Интеграция бейджа обновления в боковую панель с прямым переходом в раздел "Обновления" настроек. | **Исправлено** |
| **B18** | Выпадающие списки | Стандартные комбобоксы без поддержки темной темы и плавной навигации. | Компонент `Select` с кастомным рендерингом опций, поддержкой иконок и акцентным выделением. | **Исправлено** |
| **B19** | Управление модами | Неудобное включение/отключение модов через удаление/переименование файлов вручную. | Быстрый переключатель активности мода (`.disabled`), выявление конфликтов и циклических зависимостей. | **Исправлено** |
| **B20** | Тайлинговые WM | Падение приложения при инициализации с нулевым размером экрана (`0x0`) на Hyprland. | Функция `is_zero_viewport(ctx)` с безопасным пропуском кадра до завершения инициализации окна композитором. | **Исправлено** |
