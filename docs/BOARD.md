## Задачи агентов

### [ag-01-repro-doctor]
- [x] Добавить аргумент `--install <версия>` в `mq doctor`.
- [x] Реализовать пошаговую диагностику: Манифест -> version.json -> Java -> Клиент -> Библиотеки -> Нативные -> Ассеты -> Логирование.
- [x] Реализовать структурированный вывод с индикацией `[OK]`, `[WARN]`, `[FAIL]` и выводом точной причины.
- [x] Экспорт диагностики для кнопки «Скопировать диагностику» с санитизацией секретов (UUID, токены).

### [ag-02-version-json-core]
- [x] Обеспечить безопасную поддержку версий `26.x`, `26.1-snapshot-1`, `-pre-`, `-rc-` без предположений о `1.x.y`.
- [x] Проверить и дополнить `rules` (проверка `features`, `os.name`, `os.arch`, `os.version`).
- [x] Реализовать строгую подстановку плейсхолдеров: ни один неподставленный `${...}` не должен попадать в командную строку.
- [x] Поддержка `logging.client.file` и аргумента `-Dlog4j.configurationFile=...`.
- [x] Тесты на fixtures различных эпох (от alpha/beta до 26.x).

### [ag-03-downloader-integrity]
- [x] Реализовать схему транзакционности с каталогом `<instance>/.installing/`.
- [x] Реализовать запись и чтение `<instance>/install_state.json`.
- [x] Добавить проверку свободного места на диске перед началом загрузки.
- [x] Обеспечить повторы с экспоненциальной задержкой и джиттером для 429/5xx, учёт `Retry-After`.
- [x] Идемпотентность и атомарное переименование `.part` -> файл.

### [ag-04-java-runtime]
- [x] Реализовать модуль `crates/mq-launch/src/mojang_java.rs` для загрузки официальных рантаймов Mojang.
- [x] Поддержка `java-runtime-epsilon` (Java 25), `delta` (21), `gamma` (17), `jre-legacy` (8).
- [x] Приоритет выбора Java: (1) Подходящая системная; (2) Рантайм Mojang; (3) Adoptium/Zulu.
- [x] Автоматическая загрузка необходимой версии Java в пайплайне установки `install_game`.
- [x] Проверка `<java> -version` после установки и выставление прав `0o755`.

- [x] Проверка профилей модлоадеров Fabric, Quilt, Forge, NeoForge с наследованием `inheritsFrom`.
