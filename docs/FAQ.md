# Часто задаваемые вопросы (FAQ)

В этом документе собраны ответы на наиболее частые вопросы по использованию, настройке и безопасности **MQ Launcher**.

---

### 1. Что такое офлайн-режим и как он работает?
Офлайн-режим позволяет запускать игру и играть в одиночном режиме либо на серверах с параметром `online-mode=false` без подключения к серверам авторизации Microsoft/Mojang.

В MQ Launcher офлайн-профиль формируется строго по спецификации Java Edition: для указанного никнейма вычисляется детерминированный UUID v3 на основе алгоритма MD5 от строки `OfflinePlayer:<никнейм>` (в соответствии с RFC 4122). Это гарантирует сохранение вашего инвентаря, достижений и настроек при перезапусках.

---

### 2. Где хранятся данные лаунчера, инстансы, миры и моды?
Расположение данных зависит от операционной системы и режима работы:

* **Linux (согласно спецификации XDG):**
  * Игровые инстансы, ассеты и библиотеки: `~/.local/share/mq/`
  * Конфигурация и аккаунты: `~/.config/mq/`
  * Сетевой кэш: `~/.cache/mq/`
* **Windows 10 / 11:**
  * Игровые данные и инстансы: `%LOCALAPPDATA%\MQ\`
  * Конфигурация: `%LOCALAPPDATA%\MQ\config\`
  * Сетевой кэш: `%LOCALAPPDATA%\MQ\cache\`
* **Портативный режим (Portable Mode):**
  * При создании файла-маркера `portable.flag` рядом с исполняемым файлом лаунчера все данные изолируются в подпапке `data/` в каталоге лаунчера (удобно для USB-накопителей).

### 3. Как изменить версию Java или использовать системную JRE/JDK?
MQ Launcher умеет автоматически определять требуемую версию Java для каждой версии Minecraft (Java 8 для старых версий, Java 17 для 1.18–1.20.4, Java 21 для 1.20.5+):

1. **Автоматическая загрузка:** В разделе **«Настройки» → «Java»** лаунчер может в один клик загрузить проверенные сборки OpenJDK Adoptium Temurin (8, 17, 21).
2. **Системная Java:** Лаунчер автоматически сканирует стандартные системные пути (`/usr/lib/jvm/`, `%JAVA_HOME%`, реестр Windows).
3. **Ручной выбор:** В настройках конкретного инстанса вы можете указать собственный абсолютный путь к исполняемому файлу `java` (или `java.exe`).

Проверить доступные версии Java в системе можно через консоль:
```bash
mq java list
```

### 4. Как установить и настроить шейдеры?
MQ Launcher имеет встроенное управление шейдерпаками:

1. Перейдите в детальный просмотр инстанса на вкладку **«Шейдеры»**.
2. Перетащите файл шейдерпака (`.zip`) в окно либо поместите его в папку `shaderpacks/`.
3. Для работы шейдеров убедитесь, что в инстансе установлены моды графической оптимизации:
   - Для **Fabric / Quilt**: `Iris Shaders` + `Sodium`.
   - Для **Forge / NeoForge**: `Oculus` + `Embeddium`.
4. Лаунчер автоматически определяет вашу видеокарту и драйвер, создавая корректную конфигурацию `config/iris.properties`.

### 5. Как работает авторизация через Ely.by?
Ely.by — независимый сервис скинов и альтернативной системы авторизации.

В MQ вход через Ely.by реализован максимально безопасно:
- Никаких полей ввода логина и пароля внутри лаунчера: вход выполняется исключительно в вашем системном браузере по протоколу **OAuth2 + PKCE S256**.
- Лаунчер поднимает локальный HTTP loopback-сервер (`127.0.0.1:<порт>/callback`), принимает одноразовый код авторизации с валидацией CSRF-токена и сохраняет токен доступа.
- При запуске клиента лаунчер автоматически подключает актуальный агент `authlib-injector` (`-javaagent`), обеспечивающий отображение скинов и плащей Ely.by в игре.

### 6. Предупреждение Windows Defender SmartScreen при запуске — что делать?
При первом запуске скачанного `.exe` файла на Windows вы можете увидеть синее окно *«Система Windows защитила ваш компьютер»* (SmartScreen):

* **Почему это происходит:** MQ Launcher — независимый проект с открытым исходным кодом. Цифровые сертификаты Microsoft Authenticode (EV-сертификаты) стоят от $400 в год и выдаются только юридическим лицам. Фильтры SmartScreen по умолчанию предупреждают о любых недавно собранных исполняемых файлах, пока они не наберут «репутацию».
* **Как запустить:** Нажмите **«Подробнее»** (More info), а затем кнопку **«Выполнить в любом случае»** (Run anyway).
* **Как убедиться в безопасности:** Вы можете проверить криптографическую подпись релиза через инструмент Minisign с официальным ключом автора либо проверить аттестацию сборки Sigstore GitHub OIDC (см. [Руководство по установке](INSTALL.md)).

### 7. Как работает обновление лаунчера?
MQ Launcher содержит встроенную подсистему безопасного самообновления:

- Проверка наличия новых релизов через официальный GitHub Releases API (`MrQuster/mq`).
- Потоковая верификация целостности файла через `SHA256SUMS`.
- Атомарная замена исполняемого файла через `<exe>.new` с предварительным smoke-тестом (проверка работоспособности перед финальной подменой).
- Автоматическое сохранение предыдущей версии `<exe>.old` на случай необходимости отката.
- Если лаунчер установлен через системный пакетный менеджер (например, AUR / Pacman), автообновление предложит обновить пакет штатными средствами ОС.

Команда для проверки обновлений через CLI:
```bash
mq self-update --check
```

### 8. Нужен ли аккаунт Microsoft для игры?
- **Для одиночной игры и локальной сети:** Аккаунт Microsoft не требуется. Вы можете создать локальный **офлайн-профиль** или войти через **Ely.by**.
- **Для публичных серверов с онлайн-проверкой (`online-mode=true`):** Необходим официальный лицензионный аккаунт Microsoft с приобретенной копией Minecraft: Java Edition. Лаунчер поддерживает безопасный вход Microsoft через официальный браузерный протокол Device Code Flow.

---

### 9. Насколько безопасно хранятся мои учетные данные?
MQ строго соблюдает стандарты безопасности:
- В Linux токены сохраняются через интерфейс Secret Service API (системный Keyring / KWallet). В случае недоступности Keyring файл учетных данных создается со строгими правами доступа `0600` (чтение и запись доступны только вашему пользователю ОС).
- В Windows данные защищаются средствами Windows Data Protection API (DPAPI) и шифруются ключом профиля пользователя.
- В лаунчере полностью отсутствует телеметрия: учетные данные никогда не покидают ваш компьютер и не передаются третьим лицам.

### 10. Поддерживается ли импорт модпаков Modrinth и CurseForge?
Да, MQ полностью поддерживает форматы модпаков:
- **Modrinth (`.mrpack`):** полная загрузка и параллельная валидация хэшей SHA-1 / SHA-512 через Rayon.
- **CurseForge (`.zip`):** чтение `manifest.json`, загрузка необходимых модов и распаковка оверлеев.
- **Импорт в 1 клик:** просто перетащите файл `.mrpack` или `.zip` в главное окно лаунчера либо воспользуйтесь командой CLI:
  ```bash
  mq modpack install /путь/к/файлу.mrpack --instance МойМодпак
  ```

### 11. Как перенести сборки из MultiMC или Prism Launcher?
Вы можете импортировать готовые инстансы:
1. В MultiMC / Prism нажмите правой кнопкой на инстанс → «Экспорт инстанса» в `.zip`.
2. В MQ нажмите кнопку **«Импорт»** или перетащите архив в окно лаунчера.
3. MQ автоматически распакует конфигурации, моды, миры и настройки, проверив архив на отсутствие атак обхода путей (защита Zip-Slip). По соображениям безопасности любые сторонние скрипты запуска (`wrapper_cmd`, `PreLaunchCommand`) автоматически деактивируются.

### 12. Что делать, если игра вылетает при запуске?
1. В деталях инстанса откройте вкладку **«Консоль»** — MQ Launcher в реальном времени подсвечивает ошибки и стек вызовов.
2. Встроенный анализатор **CrashAnalyzer** автоматически сопоставит код завершения JVM и типичные ошибки модов/драйверов, выведя конкретный совет на русском языке (например, нехватка оперативной памяти, конфликт версий Java или устаревший видеодрайвер).
3. Запустите комплексную диагностику окружения в терминале:
   ```bash
   mq doctor
   ```
4. Если проблему не удается решить, проверьте совместимость установленных модов на вкладке **«Моды»** (кнопка *«Проверить зависимости и конфликты»*).
