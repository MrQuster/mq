# Часто задаваемые вопросы (FAQ)

### 1. Какие версии Minecraft поддерживает MQ?
MQ поддерживает все версии Minecraft: Java Edition — от самых ранних классических и Release 1.7.10 до актуальных релизов и снапшотов (включая экспериментальные ветки 26.x).

### 2. Какие модлоадеры поддерживаются?
Поддерживаются Fabric, Quilt, Forge и NeoForge. MQ автоматически разрешает и скачивает необходимые версии модлоадеров, профили `inheritsFrom`, зависимости и библиотеки.

### 3. Нужно ли устанавливать Java вручную?
Нет. MQ автоматически определяет совместимые системные версии Java, а при их отсутствии скачивает и настраивает изолированный рантайм нужной версии (Java 8, 17, 21, 25) от Mojang или Adoptium Temurin.

### 4. Где хранятся данные лаунчера?
* **Linux:**
  * Данные (ассеты, библиотеки, инстансы): `~/.local/share/mq`
  * Конфигурация: `~/.config/mq`
  * Кэш: `~/.cache/mq`
* **Windows:**
  * Данные и конфигурация: `%APPDATA%\mq` или каталог рядом с бинарником (в портативном режиме с `portable.flag`).

### 5. Собирает ли MQ телеметрию или персональные данные?
Нет. В MQ полностью отсутствует встроенная телеметрия, аналитика или отслеживание. Все сетевые обращения осуществляются исключительно к официальным серверам Minecraft, Mojang, Ely.by (при использовании соответствующего аккаунта), Modrinth и CurseForge (для модов). Подробнее см. [PRIVACY.md](PRIVACY.md).

### 6. Как запустить встроенную диагностику?
Выполните команду в терминале:
```bash
mq doctor
```
Для проверки конкретной версии:
```bash
mq doctor --install 1.21.1
```
